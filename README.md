## 🎎 О проекте

Это интерактивная поздравительная открытка, созданная с любовью и вниманием к деталям. Она сочетает в себе:

* **Эстетику японского стиля** — фон с сакурой, полупрозрачные элементы, минималистичный дизайн
* **Атмосферу командной строки** — терминал с реалистичным звуком печати и неоновым белым текстом
* **Живого аватара** — милый персонаж (лисёнок или твоё фото), который ходит, танцует, зевает и реагирует на клики
* **Слайд-шоу из фотографий** — 10 тёплых снимков с душевными подписями
* **Печатающиеся пожелания** — справа появляются трогательные фразы с эффектом печатной машинки
* **Праздничный финал** — салют из букв имени, фотографии по кругу и возможность пересмотреть открытку

Проект полностью работает в браузере, не требует сервера и отлично адаптирован для мобильных устройств.

### Требования

Проект не требует установки дополнительных зависимостей. Достаточно:
- Современного браузера (Chrome, Firefox, Safari, Edge)
- Любого локального веб-сервера (или просто открыть `index.html`)
